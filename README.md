
# BudgetPlanner

A personal finance planning application built with C# and .NET 10.

## About

BudgetPlanner is a console application designed to forecast personal cash flow over a six-month period.

The application helps users understand when money will be available, identify potential cash shortages, and plan expenses.

## Planned Features

- Multiple bank accounts
- Recurring and one-time income
- One-time and recurring expenses
- Optional daily spending budget
- Credit card and grace period tracking
- Six-month cash flow forecasting
- Financial analysis and expense optimization

## Technologies

- C#
- .NET 10
- Git
- JSON
